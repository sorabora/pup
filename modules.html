    core (always available)

    These functions need no include — they're always in scope.

    • wait(seconds) — pauses execution for the given number of seconds before continuing. Throws if seconds is negative.
    • eval(fn) — calls a function value fn and returns its result. Throws if fn isn't a function.
    • toString(value) — converts any value to a string (objects are JSON-stringified; enum instances become their underlying value).
    • toNumber(value) — converts a value to a number (booleans become 0/1, null/undefined become NaN).
    • toBool(value) — converts a value to a boolean using common-sense rules (0, "", "false", null/undefined are falsy).
    • restart() — re-runs the current program from the top. Only works while a program is actually running. 
    include console

local n = toNumber("42")
print(n + 1)

wait(1)
print("one second later")

    console

    include console

    Text output and user input for the output panel.

    • print(...values) — writes the given values (space-separated) to the output log, followed by a newline.
    • ask(...prompt) — prints the prompt, waits for the user to type a value into the command line and press Enter, echoes what they typed back into the log, and returns it.
    • dialog(...prompt) — same as ask, but the entered value is not echoed back into the log (useful for input you don't want cluttering the output). 
    include console

print("Hello, world!")

local name = ask("What's your name?")
print("Hi, " + name + "!")

local secret = dialog("Enter a password:")

    utils

    include utils

    Small helpers, currently just utils.time for reading the local clock.

    • utils.time.currentYear()
    • utils.time.currentMonth() — 1-12 (January is 1, not 0).
    • utils.time.currentDay() — day of month.
    • utils.time.currentHour() — 0-23.
    • utils.time.currentMinute()
    • utils.time.currentSecond()

print("The year is " + utils.time.currentYear())
print("Right now it's " + utils.time.currentHour() + ":" + utils.time.currentMinute())

    vectors

    include vectors

    Simple 2D/3D point-like types. Any field left out defaults to 0. (These same types are also available through include game, so you usually don't need to include both.)

    • new Vector2(x, y) — has .x and .y fields.
    • new Vector3(x, y, z) — has .x, .y, and .z fields. 
    include console
include vectors

local pos = new Vector2(10, 20)
print(pos.x)
print(pos.y)

local zero = new Vector3()
// zero.x, zero.y, zero.z are all 0

    io

    include io

    Keyboard input. Most useful alongside game for reading input every frame inside game.mainLoop.

    • isKeyDown(key) — true for every frame the key is held down.
    • isKeyPressed(key) — true only on the single frame the key was first pressed (it won't fire again until the key is released and pressed again), useful for things that should happen once per press instead of every frame it's held. 
    include console
include io

if isKeyDown("w"):
  print("w is currently held down")
end

if isKeyPressed(" "):
  print("space was just pressed")
end

    game

    include game

    A minimal 2D canvas for making simple games: a window, solid shapes, text, and a frame loop. Vector2/Vector3 and the alignment constants center, left, and right are also exposed once this module is included.

    • game.createWindow(width, height) — creates and shows the canvas. Call this once before any other game.* drawing function.
    • game.fillColor(color) — sets the color (any CSS color string, e.g. "#ff0000" or "red") used by background, rect, circle, and text.
    • game.background(color) — fills the entire canvas with a color (also updates the fill color).
    • game.rect(x, y, width, height) — draws a filled rectangle.
    • game.circle(x, y, radius) — draws a filled circle.
    • game.text(text, x, y, fontSize = 16, posmode = "left") — draws text. posmode is "left", "center", or "right" and controls horizontal alignment relative to x.
    • game.clear() — clears the entire canvas to transparent.
    • game.mainLoop(fn) — calls fn once per animation frame (via requestAnimationFrame) until the program is stopped or restarted. This is where you put your game's update/draw code. 
    include console
include game
include io

game.createWindow(400, 300)
game.fillColor("#3388ff")

local x = 10

game.mainLoop(function()
  game.clear()
  if isKeyDown("d"):
    x += 2
  end
  game.circle(x, 150, 20)
  game.text("Score: 0", 10, 20, 16, left)
end)

    http

    include http

    Makes HTTP requests. Responses are auto-parsed as JSON when the content type or body shape looks like JSON, otherwise you get the raw text back. A non-2xx status throws an error.

    • http.request(method, url, body = null, headers = {}) — full control: any method, an optional body (objects are JSON-encoded automatically with a Content-Type header added if you didn't set one), and optional headers.
    • http.response(url), http.response(method, url), or http.response(method, url, headers) — a shorthand for a GET-style request without a body. 
    include console
include http

local data = http.response("https://example.com/api")
print(data)

local created = http.request("POST", "https://example.com/api", { name: "pup" })
print(created)

    enums

    include enums

    A restricted set of allowed string values. Constructing an enum with a value outside the allowed list throws.

    • enums.createEnum([...options]) — returns a new enum type. options is a non-empty array of allowed values (compared as strings).
    • enums.Enum(enumType, value) — constructs an instance of an enum type returned by createEnum. Its .value field holds the underlying string, and it stringifies to that value automatically. Throws if value isn't one of the allowed options. 
    include console
include enums

local Direction = enums.createEnum(["up", "down", "left", "right"])
local facing = enums.Enum(Direction, "up")

print(facing)
// throws: invalid enum value
// local bad = enums.Enum(Direction, "sideways")

    html

    include html

    Builds HTML as plain strings from ordinary pup values — arrays, objects, functions — instead of hand-concatenating markup. It has no dependency on the DOM, so it works standalone (build a string, do whatever you want with it) or paired with htmlapp to actually put that string on the page, or with ssr to write it out server-side. Text you pass through is not auto-escaped — escape it yourself with html.text/html.escape wherever it might contain user input.

    • html.el(tag, attrs, children) — builds one element. attrs is an object of attribute name/value pairs (true renders a bare attribute, false/null omits it entirely, an array is joined with spaces for class and commas otherwise); values are automatically escaped. children is a string, a number, an array of them (nested arrays are flattened), or null for none. Known void elements (img, br, input, etc.) are rendered self-closing.
    • html.text(value) / html.escape(value) (alias) — HTML-escapes a value so it's safe to drop into markup as text.
    • html.attr(value) — escapes a value for safe use inside an attribute (used internally by el; exposed in case you're building attribute strings by hand).
    • html.list(items, renderFn) — calls renderFn(item, index) for every item in an array and joins the results into one string. This is the easiest way to turn a pup array (a hand of cards, a list of players, ...) into repeated markup.
    • html.style(props) — turns an object of CSS properties into an inline style="..."-ready string, e.g. for passing as an el attribute.
    • html.css(rules) — turns an object of { selector: { property: value } } into a full CSS stylesheet string, ready to hand to htmlapp.style (or write to a .css file via ssr.render). 
    include console
include html

local hand = [
  { suit: "hearts", value: "A" },
  { suit: "spades", value: "K" }
]

function renderCard(card, i)
  return html.el("div", { class: "card" }, html.text(card.value) + " of " + html.text(card.suit))
end

local cardsHtml = html.list(hand, renderCard)
local page = html.el("div", { class: "hand" }, cardsHtml)

print(page)

    htmlapp

    include htmlapp browser only

    Puts real HTML (and CSS) onto the page — into the output panel, or into elements you select — for building simple UIs instead of drawing to a canvas. Pairs naturally with html for building the markup/CSS strings it renders.

    • htmlapp.render(html) — replaces the app's default output area with the given HTML string.
    • htmlapp.mount(html, selector) — like render, but targets a specific element (a CSS selector string) instead of the default area.
    • htmlapp.clear(selector) — empties an element (defaults to the app's output area).
    • htmlapp.setHtmlAttribute(selector, property, value) / htmlapp.setProperty(...) (alias) — sets an attribute or property (class, value, checked, and disabled are handled specially so they behave like you'd expect on form elements). Pass false/null to remove it.
    • htmlapp.getHtmlAttribute(selector, property) / htmlapp.getProperty(...) (alias) — reads an attribute or property back.
    • htmlapp.style(cssText) — injects (or replaces) a single <style> tag with the given CSS text, so anything you've rendered can actually be styled. Pass it a plain CSS string, or the output of html.css(...).
    • htmlapp.setTitle(title) — sets the browser tab's title.
    • htmlapp.export(html, title, css) — returns a complete, standalone HTML document (as a string) wrapping the given content, with an optional CSS string embedded in its <head>.
    • htmlapp.download(html, filename, title, css) — builds that same standalone document and triggers a browser download of it. 
    include html
include htmlapp

local page = html.el("div", { class: "hand" }, "<b>your move</b>")
local pageCss = html.css({ ".hand": { display: "flex", gap: "8px" } })

htmlapp.style(pageCss)
htmlapp.render(page)

    ssr node.js only

    include ssr

    Server-side rendering: writing out an HTML string when running under Node.js (via the "Node.js" or "HTML" transpile targets).

    • ssr.render(html, filePath) — with a filePath, writes the HTML string to that file on disk; without one, prints it to stdout. (In the browser-based Run panel, it falls back to writing into the output log so you can still see the result.) 
    include ssr

ssr.render("<h1>Hello</h1>", "out.html")
